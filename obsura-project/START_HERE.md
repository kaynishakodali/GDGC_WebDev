# Obsura: project kit (v2)

1. Put your Google AI Studio landing hero (code + chrome-head image) into `existing-landing/`. It is reused unchanged.
2. Open this folder in your coding tool (or upload the zip).
3. Paste/attach `OBSURA_MASTER_PROMPT.md` and tell the tool: "Follow this exactly. If a project already exists, reconcile it with this spec and keep what works. Start with step 1 (inspect and report) before writing code."

Folder map (paths match the prompt):
- `OBSURA_MASTER_PROMPT.md`: the full, final specification (frontend only)
- `existing-landing/`: your generated landing hero, untouched
- `public/seed/seed.json` + `public/seed/images/`: the only content source
- `docs/`: assignment PDF and reference screenshots (landing, galaxy gallery, details pop-up, RBAC)
